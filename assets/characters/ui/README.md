# Random shape icon

random-shapes-original.png is the unmodified imagegen result produced for the user's requested random body-shape control on 2026-10-07. The supplied prompt described a transparent compact icon combining the game's rounded body shapes. The original is retained as provenance.

random-shapes-24.png and random-shapes-32.png are ordinary display derivatives: transparent edge trimming (5% fuzz) and proportional downsampling with ImageMagick. No art was redesigned. The UI accepts a randomShapeImage asset path and uses the 32px derivative in a 24px display box.
