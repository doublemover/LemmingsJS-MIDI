# Lucide icon subset

These SVGs are a small vendored subset of [Lucide](https://lucide.dev/), downloaded from the project's [first-party repository](https://github.com/lucide-icons/lucide/tree/main/icons) on 2026-10-07. No runtime package or network request is required.

Upstream source: https://raw.githubusercontent.com/lucide-icons/lucide/main/icons/{name}.svg

License verified against https://lucide.dev/license and https://raw.githubusercontent.com/lucide-icons/lucide/main/LICENSE on 2026-10-07. The complete upstream notice is included in LICENSE: ISC, plus MIT for the identified Feather-derived icons. Preserve that file when distributing these SVGs. Icons are unmodified; CSS masks supply the interface color.

Character selector thumbnails are generated from this repository's character art instead of using generic icons. Regenerate those with `node scripts/generate-character-previews.js`.
