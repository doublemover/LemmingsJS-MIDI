Independent voices in this cell

Up to 8 pitches, each with its own velocity and duration. Blank dynamics use cell/project defaults. Scalar controls edit the first voice; Rest erases the whole cell. Poly voices require event or game-tick playback.

Base pitch transform (saved behavior)

Layers add transpose + 12 x octaves + interval x ((counter - 1) modulo span), then project scale/range apply. The grid shows entered notes; moving row notes show dispatched pitches.

Ordered transform layers

Up to 4 layers run in order after the base transform. Repeat count includes the original; spacing uses game ticks. Conditions use event/pass/trigger-bar counters. At most 16 outputs per cell and 256 per phrase; local tests retain 64. Limits appear in status/output pressure.

Counter timing

Counters start at 1. Phase 0 selects N, 2N; phase 1 selects 1, N+1. An event pass is one grid traversal. Phrase passes count started or fully consumed phrases, as selected. Trigger bars use level ticks at the project BPM and time signature, sampled once at the trigger. Pause freezes the bar; speed changes its wall-time rate. Changing BPM/signature recomputes position. Local tests use independent event/pass counters and the same level bar.

Compact capture keeps the saved note-off order. Keep gaps quantizes note-on times from the first note to the nearest cell, keeps overlapping lengths. Mono keeps the last onset in each cell; Poly retains up to 8 independent voices. Onset Replace rebuilds the entire grid including rests; Overdub preserves untouched cells and existing modifiers. Compact Overdub places captured notes in saved note-off order into successive cells. Leading silence is omitted. The current game tick length is frozen for capture; playback follows game ticks. Capture stops admitting notes at 1024; Commit or Cancel closes held notes.
