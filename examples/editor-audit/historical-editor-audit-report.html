Fixes and remaining findings

  1. FIXED: MCP callE2E nested an unresolved Promise inside its result. Awaiting the method now preserves async editor results/resources and catches async rejection.
  2. FIXED: Xmas 1991 and Xmas 1992 each referenced a nonexistent fifth archive part. Both DAT files have four 2048-byte parts; menus now contain four entries.
  3. ADDED: export-all-levels is a separate non-overwriting archival JSON exporter. Existing export-all-packs exports sprites only; MCP level.export supports current-level NXLV/LVL, not all-pack JSON.
  4. REMAINING: Console-driven level.loadText/loadSaved updates the model and preview but may leave visible metadata fields showing the prior level. UI file import updates the fields correctly. See console captures versus final UI-import overviews.
  5. REMAINING: Exporting the active project level re-derives its display title from the NXLV header and loses a separately assigned project label. NXLV contents remain intact. A product decision is needed about alias versus header ownership.
  6. ASSETS: No custom bitmap/style import control or asset editing UI exists. Offline PNG/DAT tools provide sprite export and patching. Editor project archives contain text files and do not bundle the required base DAT art. A pack archive is application-specific JSON, not a ZIP or universally portable NeoLemmix pack.
  7. ASSETS: Generic palette names and zero-dimension placeholder entries reduce discoverability. Classic LVL export is lossy for extended editor data; special graphics references are retained in the new classic JSON but editor conversion has narrower support.
  8. SOURCE REVIEW: exportAllPacks.js uses URL.pathname for its default config path and catches failures by falling back to lemmings. On Windows this path handling can hide other configured packs. Not changed or counted as a live export test.
  9. ENVIRONMENT: Node 26 stalled during official Chromium extraction and Playwright cleanup. Official Node 22 plus Windows archive extraction completed the same browser tests cleanly. Initial interrupted run is not counted as a clean pass.
  10. UNRUN: Cross-browser/physical touch/accessibility audit, external archive formats with arbitrary third-party packs, real hardware MIDI, deployment and performance soak tests. The advisory solver is not a proof of solvability.

Reproduce and recover

Use Node 20+ (Node 22 verified), npm ci, and npm run export-all-levels -- <new-directory>. The destination must not already exist. Exported JSON is classic archival data, not the editor’s package-import format. Its manifest records each pack/rank/index, title and checksum; classic fields roundtrip through LevelWriter/LevelReader.

The evidence archive includes raw browser results, validation/playtest snapshots, all 324 level JSON files, controls inventory, scripts, screenshots, the local commit hash, a patch and a Git bundle. The bundle requires the published base commit. No pushes or deployment occurred. The separate MIDI sequencer review was not undertaken.
